## Avukata özellikle sorulacaklar
1. Oyun içi varlık (yang, won, item, karakter/hesap) alım-satımına aracılığın, oyun yayıncısının (Gameforge vb.)
   kullanım koşullarıyla ilişkisi ve olası riskler.
2. Dijital içerik / anında ifa edilen hizmette **cayma hakkı istisnası** (Mesafeli Sözleşmeler Yönetmeliği md.15)
   metninin ve onay kutusunun yeterliliği.
3. Bakiye (cüzdan) sisteminin 6493 sayılı Ödeme Hizmetleri Kanunu karşısındaki durumu (ön ödemeli/elektronik para
   sayılmaması için koşullar), çekilebilir / çekilemez bakiye ayrımı.
4. Çekiliş ve şans çarkı (Milli Piyango İdaresi izni), komisyon ve e-Gider Pusulası uygulamasının vergi yönü.
5. KVKK: TC kimlik no saklama süresi, yurt dışına aktarım (Brevo e-posta servisi AB sunucuları), açık rıza gereken
   durumlar.
